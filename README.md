# Kubernetes Edge Scheduling

Репозиторий содержит скрипты для проведения экспериментального исследования стратегий планирования Kubernetes в гетерогенной edge-среде.

Работа выполнялась в рамках дипломной работы на тему: "Исследование и разработка стратегий планирования в Kubernetes для гетерогенных узлов системы периферийных вычислений"

В этом репозитории находятся скрипты для генерации KWOK-кластера, создания workload-манифестов, запуска экспериментов, сбора состояния кластера, расчёта метрик и построения сравнительных результатов.

Реализация кастомного планировщика EdgeFit вынесена в отдельный fork репозитория `kubernetes-sigs/scheduler-plugins`.

Репозиторий с реализацией: https://github.com/Deymos01/scheduler-plugins-k8s-in-edge/tree/edgefit
